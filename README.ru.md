[English](README.md) | Русский

Я iOS-инженер с более чем 7 годами профессионального опыта в разработке приложений и SDK для платформ Apple.

С 2019 года работаю в Carrot quest: разрабатываю iOS-приложения и участвую в развитии SDK компании. С 2023 года полностью сосредоточился на SDK и как единственный iOS-разработчик поддерживаю и развиваю библиотеку, интегрированную примерно в 100 клиентских приложений.

Моя работа включает разработку нативных интерфейсов, интеграции SDK, обмен сообщениями в реальном времени, push-уведомления, оптимизацию производительности и управление релизами.

Вне работы я создаю собственные приложения, участвую в open-source-проектах и изучаю технологии за пределами экосистемы Apple — в том числе разработку документации и автоматизацию процессов с Claude Code и Codex.

### Избранные проекты

- **[Документация Carrot quest SDK](https://developers-sdk.carrotquest.io/)** — Создал и запустил сайт документации на VitePress для интеграций с iOS, Android и Flutter.

- **[Just-Diary](https://github.com/manzick/Just-Diary)** — Open-source приложение-дневник на SwiftUI для iPhone, iPad и macOS. Использует Core Data, интеграцию с iCloud и импорт/экспорт JSON.

- **[icloud-synk](https://github.com/manzick/icloud-synk)** — Мой форк open-source клиента синхронизации iCloud Drive для Linux. Добавил синхронизацию нескольких папок, улучшения безопасности данных и поддержку Docker/ARM64.

- **[BackgroundMusic — PR #741](https://github.com/kyleneideck/BackgroundMusic/pull/741)** — Добавил совместимость с браузером Arc в open-source утилиту для управления звуком в macOS. Изменения приняты в основной проект.
